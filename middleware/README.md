# 外部中间件

`middleware/` 用于统一存放移植到本项目的外部中间件源码。为保持项目独立性并减少仓库存储占用，采用直接拷贝所需源码的方式引入，由本项目统一管理版本；不 clone 上游仓库，也不通过 Git 子模块引入。

## 移植与维护约定

- 每个中间件使用独立子目录，目录名沿用上游组件名称。
- 按需引入源码、头文件及必要的许可证和说明文档，不携带上游 `.git` 目录、提交历史、无关示例或构建产物。
- 保留上游源码中的版权和许可声明。
- 引入或升级时，在本文件中记录组件来源、tag、完整 commit 和引入文件，确保可以追溯源码版本。
- 存在项目适配、功能裁剪或编译配置时，在组件目录的 `README.md` 中说明；升级时核对并保留仍需使用的适配修改。
